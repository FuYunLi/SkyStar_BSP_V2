# SkyStar BSP V2 · Debug 记录规范

> **适用范围**：记录项目开发过程中**难以察觉**、**调试多轮**的软硬件逻辑类问题。
> 代码拼写错误、简单语法错误不在此列。

---

## 一、 文件命名规范

```
00_Debug_Standard.md     ← 本规范文件，不参与序号排列
01_<BugID>_<简短标题>.md
02_<BugID>_<简短标题>.md
...
```

- **BugID** 格式：`YYYYMMDD`，取首次发现该问题的日期。
- **简短标题**：不超过 20 个字符的中文描述，使用下划线连接多个词语（如 `MultiTimer单次触发续期缺失`）。
- 完整示例：`01_20260608_MultiTimer单次触发续期缺失.md`

---

## 二、 Bug 日志模板

## 三、 严重等级判定标准

| 等级 | 标识 | 判定依据 |
|------|------|----------|
| 致命 | 🔴 | 导致系统宕机、死锁、数据损坏或功能完全失效，且**难以感知**（无明显异常打印） |
| 严重 | 🟠 | 导致核心功能异常，但系统仍在运行，需要多轮调试才能定位 |
| 一般 | 🟡 | 功能部分受损，触发条件特定，复现较困难 |
| 轻微 | 🔵 | 行为不符合预期，但不影响主流程，或有明显错误日志提示 |

---

## 四、 Bug 类型说明

| 类型 | 说明 |
|------|------|
| **调度逻辑** | 裸机调度器（MultiTimer、轮询等）的触发时序、续期机制、优先级等问题 |
| **硬件时序** | GPIO 电平、PWM 占空比、DMA 传输时序、总线协议建立/保持时间等问题 |
| **接口语义** | 对库函数、HAL API 或中间件接口的行为预期与实际行为不符 |
| **并发竞争** | 中断与主循环、回调函数之间的共享变量竞争或重入问题 |
| **配置陷阱** | CubeMX 配置、链接脚本、编译选项等配置层面导致的隐蔽问题 |
| **其他** | 不属于以上类型的架构设计或业务逻辑问题 |
