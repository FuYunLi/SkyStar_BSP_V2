# SkyStar BSP V2 中间件集成规划

## 概述

本文档详细说明各中间件的集成方式、配置要点和验收标准。

***

## MultiTimer - 软件定时器调度

### 基本信息
- **用途**：统一调度所有软件定时器
- **开源地址**：https://github.com/0x1abin/MultiTimer
- **引入阶段**：阶段零
- **特性**：单文件实现，轻量级（~200行），支持单次/周期模式

### 集成方式

```
Middleware/MultiTimer/
├── multi_timer.h    # 头文件
└── multi_timer.c    # 实现文件
```

### API 设计

```c
/* MultiTimer 接口适配 */
typedef struct multi_timer multi_timer_t;
typedef void (*multi_timer_cb_t)(multi_timer_t *timer, void *arg);

struct multi_timer
{
    uint32_t          start;      /* 启动时间戳 */
    uint32_t          interval;   /* 定时间隔 */
    multi_timer_cb_t  callback;   /* 回调函数 */
    void             *arg;        /* 用户数据 */
    bool              repeat;     /* true=周期, false=单次 */
    multi_timer_t    *next;       /* 链表指针 */
};

/* 初始化调度器 */
void multi_timer_init(void);

/* 添加定时器 */
multi_timer_t *multi_timer_add(multi_timer_t *timer, uint32_t interval_ms,
                                multi_timer_cb_t cb, void *arg, bool repeat);

/* 删除定时器 */
void multi_timer_del(multi_timer_t *timer);

/* 统一调度（main while(1) 中调用） */
void multi_timer_process(void);
```

### 验收标准
- 所有常驻任务通过 MultiTimer 回调驱动
- `bsp_board.c` 不含任何业务逻辑或测试代码

## LwRB - 轻量级环形缓冲区

### 基本信息
- **用途**：UART/SPI 等接口层的接收/发送缓冲区
- **开源地址**：https://github.com/MaJerle/lwrb
- **引入阶段**：阶段一 M1
- **特性**：单头文件库，零拷贝设计

### 集成方式

```
Middleware/LwRB/
└── lwrb.h    # 单头文件库
```

### 关键 API

```c
/* 初始化环形缓冲区 */
void lwrb_init(lwrb_t *rb, void *buf, size_t size);

/* 写入数据 */
size_t lwrb_write(lwrb_t *rb, const void *data, size_t len);

/* 读取数据 */
size_t lwrb_read(lwrb_t *rb, void *data, size_t len);

/* 获取线性块地址（零拷贝读取） */
void *lwrb_get_linear_block_read_address(lwrb_t *rb);
size_t lwrb_get_linear_block_read_length(lwrb_t *rb);

/* 跳过已读数据 */
void lwrb_skip(lwrb_t *rb, size_t len);
```

### 验收标准
- UART 接口层使用 lwrb 实现 DMA 循环接收
- 支持零拷贝读取，减少内存拷贝

## Letter Shell - 串口交互终端

### 基本信息
- **用途**：串口交互终端，所有功能的验收入口
- **开源地址**：https://github.com/NevermindZZT/letter-shell
- **引入阶段**：阶段一 M2
- **特性**：支持自动补全、历史记录、权限控制

### 集成方式

```
Middleware/letter-shell/
├── src/
│   ├── shell.c
│   ├── shell_ext.c
│   └── shell_port.c    # 移植文件
├── inc/
│   ├── shell.h
│   └── shell_cfg.h     # 配置文件
└── shell_cfg.h
```

### 移植要点

```c
/* shell_port.c - 对接 port_uart */

/* Shell 输出函数 */
void shellWrite(char *data, unsigned short len)
{
    port_uart_write_sync(PORT_UART_1, (uint8_t *)data, len, BSP_WAIT_FOREVER);
}

/* Shell 读取函数 */
short shellRead(char *data, unsigned short len)
{
    return port_uart_read(PORT_UART_1, (uint8_t *)data, len);
}

/* Shell 初始化 */
void shell_init(void)
{
    /* 注册第一个命令：version */
    shellRegister(shellGetCurrent(), &shellVersionCmd);
}
```

### 验收标准
- 串口输入 `version` 回车，终端输出版本信息
- 所有后续功能通过 Shell 命令验收

## EasyLogger - 异步日志系统

### 基本信息
- **用途**：异步日志系统，支持多级别、颜色输出
- **开源地址**：https://github.com/armink/EasyLogger
- **引入阶段**：阶段一 M3
- **特性**：异步输出、多级别、颜色区分、Flash 存储

### 集成方式

```
Middleware/EasyLogger/
├── src/
│   ├── elog.c
│   ├── elog_utils.c
│   └── elog_port.c    # 移植文件
├── inc/
│   ├── elog.h
│   └── elog_cfg.h     # 配置文件
└── elog_cfg.h
```

### 移植要点

```c
/* elog_port.c - 对接 port_uart */

/* 日志输出函数 */
void elog_port_output(const char *log, size_t size)
{
    port_uart_write_async(PORT_UART_1, (uint8_t *)log, size, NULL, NULL);
}

/* 日志初始化 */
void elog_init(void)
{
    /* 初始化 EasyLogger */
    elog_init();
    
    /* 设置日志格式 */
    elog_set_fmt(ELOG_LVL_ASSERT, ELOG_FMT_ALL);
    elog_set_fmt(ELOG_LVL_ERROR, ELOG_FMT_LVL | ELOG_FMT_TAG | ELOG_FMT_TIME);
    elog_set_fmt(ELOG_LVL_WARN, ELOG_FMT_LVL | ELOG_FMT_TAG | ELOG_FMT_TIME);
    elog_set_fmt(ELOG_LVL_INFO, ELOG_FMT_LVL | ELOG_FMT_TAG | ELOG_FMT_TIME);
    elog_set_fmt(ELOG_LVL_DEBUG, ELOG_FMT_ALL & ~ELOG_FMT_FUNC);
    
    /* 启动日志 */
    elog_start();
}
```

### 日志宏定义

```c
/* bsp_board.h 中定义 */
#define log_a(tag, ...)  elog_a(tag, __VA_ARGS__)  /* Assert */
#define log_e(tag, ...)  elog_e(tag, __VA_ARGS__)  /* Error */
#define log_w(tag, ...)  elog_w(tag, __VA_ARGS__)  /* Warning */
#define log_i(tag, ...)  elog_i(tag, __VA_ARGS__)  /* Info */
#define log_d(tag, ...)  elog_d(tag, __VA_ARGS__)  /* Debug */
#define log_v(tag, ...)  elog_v(tag, __VA_ARGS__)  /* Verbose */
```

### 验收标准
- Shell 输入 `log_test`，终端输出带颜色的 I/W/E 三级日志

## LittleFS - Flash 文件系统

### 基本信息
- **用途**：W25Q128 Flash 文件系统
- **开源地址**：https://github.com/littlefs-project/littlefs
- **引入阶段**：阶段四 M16
- **特性**：掉电安全、磨损均衡、轻量级

### 集成方式

```
Middleware/LittleFS/
├── lfs.c
├── lfs.h
├── lfs_util.h
└── lfs_port.c    # 移植文件
```

### 移植要点

```c
/* lfs_port.c - 对接 W25Q128 */

/* 读取块 */
int lfs_port_read(const struct lfs_config *c, lfs_block_t block,
                  lfs_off_t off, void *buffer, lfs_size_t size)
{
    uint32_t addr = block * c->block_size + off;
    return dev_w25q_read(addr, buffer, size) == BSP_OK ? 0 : -1;
}

/* 编程块 */
int lfs_port_prog(const struct lfs_config *c, lfs_block_t block,
                  lfs_off_t off, const void *buffer, lfs_size_t size)
{
    uint32_t addr = block * c->block_size + off;
    return dev_w25q_write(addr, buffer, size) == BSP_OK ? 0 : -1;
}

/* 擦除块 */
int lfs_port_erase(const struct lfs_config *c, lfs_block_t block)
{
    uint32_t addr = block * c->block_size;
    return dev_w25q_erase_sector(addr) == BSP_OK ? 0 : -1;
}
```

### 验收标准
- Shell `lfs_boot_count` 每次输出递增的启动计数

## MultiButton - 多按键管理

### 基本信息
- **用途**：状态机按键管理，支持单击/双击/长按
- **开源地址**：https://github.com/0x1abin/MultiButton
- **引入阶段**：阶段二 M8
- **特性**：状态机驱动，支持多种按键事件

### 集成方式

```
Middleware/MultiButton/
├── multi_button.h
└── multi_button.c
```

### 使用示例

```c
/* 按键事件回调 */
void button_callback(void *btn)
{
    uint8_t event = get_button_event(btn);
    
    switch (event)
    {
        case PRESS_DOWN:
            log_i("Button", "按下");
            break;
        case PRESS_UP:
            log_i("Button", "抬起");
            break;
        case SINGLE_CLICK:
            log_i("Button", "单击");
            break;
        case DOUBLE_CLICK:
            log_i("Button", "双击");
            break;
        case LONG_PRESS_START:
            log_i("Button", "长按开始");
            break;
        case LONG_PRESS_HOLD:
            log_i("Button", "长按保持");
            break;
    }
}

/* 按键初始化 */
void button_init(void)
{
    Button btn;
    button_init(&btn, read_button_pin, 0, BTN_ID_KEY1);
    button_attach(&btn, SINGLE_CLICK, button_callback);
    button_attach(&btn, DOUBLE_CLICK, button_callback);
    button_attach(&btn, LONG_PRESS_START, button_callback);
    button_start(&btn);
}
```

### 验收标准
- 按键支持单击、双击、长按识别
- 通过 MultiTimer 驱动按键扫描

```c
/* lv_port_disp.c - 对接 ST7789 */

/* 显示刷新回调 */
void disp_flush(lv_disp_drv_t *disp_drv, const lv_area_t *area, lv_color_t *color_p)
{
    int32_t x, y;
    int32_t w = area->x2 - area->x1 + 1;
    int32_t h = area->y2 - area->y1 + 1;
    
    /* 设置窗口 */
    dev_st7789_set_window(area->x1, area->y1, area->x2, area->y2);
    
    /* 写入数据 */
    dev_st7789_write_data((uint8_t *)color_p, w * h * sizeof(lv_color_t));
    
    /* 通知刷新完成 */
    lv_disp_flush_ready(disp_drv);
}
```

### 验收标准
- LVGL 内置 Demo 正常运行
- 触摸输入正常响应

## CmBacktrace - 故障诊断

### 基本信息
- **用途**：HardFault 时打印调用栈
- **开源地址**：https://github.com/armink/CmBacktrace
- **引入阶段**：阶段零
- **特性**：自动打印调用栈、寄存器信息

### 集成方式

```
Middleware/CmBacktrace/
├── cm_backtrace.c
├── cm_backtrace.h
├── cmb_flash.c    # Flash 移植
└── cmb_cfg.h      # 配置文件
```

### 使用示例

```c
/* HardFault 处理 */
void HardFault_Handler(void)
{
    cm_backtrace();
    while (1);
}
```

### 验收标准
- HardFault 时打印完整的调用栈和寄存器信息
