# SkyStar BSP V2 设计原则

## 核心设计原则

### 1. 规范先行
第一个提交只建框架和规范，不写一行业务代码。

### 2. Shell 最早引入
第三个里程碑就移植 Letter Shell，此后所有验收通过 Shell 命令执行。

### 3. 接口→驱动→Demo 严格分层
同一总线的接口层完成后，立刻做一个最简 Demo 验收，再进入下一总线。

### 4. EasyLogger 紧随 Shell
日志和交互工具都到位后，后续所有驱动开发才有完整的调试手段。

### 5. 按硬件复杂度升序
GPIO → UART → SPI → I2C → PWM → 传感器 → 电机 → 音频 → 网络

## CubeMX 全局配置检查清单

为了彻底解决代码耦合和配置遗漏问题，请在建立工程时严格检查以下全局参数：

### 1. System Core -> RCC (复位与时钟控制)
- **HSE (High Speed Clock)**: 选择 `Crystal/Ceramic Resonator` (开发板板载 8MHz 外部晶振)。
- **LSE (Low Speed Clock)**: 保持 `Disable` (使用外部高精度 SD3078，无需 MCU 内部低速时钟)。

### 2. System Core -> SYS (系统)
- **Debug**: 选择 `Serial Wire` (SWD 下载与调试)。
- **Timebase Source**: 选择 `SysTick` (裸机默认即可)。

### 3. Clock Configuration (时钟树配置)
- **Input frequency**: 填写 `8` MHz。
- **PLL Source Mux**: 选择 `HSE`。
- **Main PLL**: 配置 `/M` = 4, `*N` = 168, `/P` = 2, `/Q` = 4。
- **System Clock Mux**: 选择 `PLLCLK`。
- **APB1 Prescaler**: 选择 `/4` (输出 42MHz，因最大限制为 42MHz)。
- **APB2 Prescaler**: 选择 `/2` (输出 84MHz，因最大限制为 84MHz)。
- 确认核心总线 **HCLK** 为 `168` MHz。

### 4. Project Manager -> Project
- **Toolchain / IDE**: 选择 `MDK-ARM`。
- **Linker Settings**: `Minimum Heap Size` 设为 `0x1000` (4KB)，`Minimum Stack Size` 设为 `0x1000` (4KB)。为后续打印、缓冲预留空间。

### 5. Project Manager -> Code Generator
- 勾选 **Copy only the necessary library files** (只拷贝需要的库文件，缩减体积)。
- **【极度重要】** 强制勾选 **Generate peripheral initialization as a pair of '.c/.h' files per peripheral** (为每个外设独立生成 `.c/.h` 文件。这是实现 V2 代码模块化、保持 `main.c` 清爽的绝对基础！)。

## 目录结构规范

```
BSP/
├── Board/           # 板级支持包核心
│   ├── bsp_board.h  # 统一状态码、断言宏、常用宏

│   └── bsp_config.h # 系统时钟配置

├── Interface/       # 硬件抽象层（HAL 隔离）
│   ├── port_gpio.h/c
│   ├── port_uart.h/c

│   └── port_i2c.h/c

└── Driver/          # 设备驱动层

├── demos/           # 独立 Demo，Shell 触发
│   ├── demo_led_flow.c/h
│   └── demo_ws2812.c/h

│   ├── task_led_status.c/h

```

## 分层规范

| 层级 | 职责 | 允许依赖 | 禁止依赖 |
|-----|------|---------|---------|
| **Interface 层** | 隔离 HAL 库，提供统一硬件抽象 | HAL 库、bsp_board.h | 应用层头文件 |
| **Driver 层** | 设备驱动，不直接操作寄存器 | Interface 层、bsp_board.h | HAL 库、MCU 厂商头文件 |
| **Demo 层** | 独立功能演示，Shell 触发 | Driver 层、Middleware | Interface 层、HAL 库 |
| **App 层** | 应用逻辑，注册任务和 Demo | 所有层 | 直接操作硬件 |

***

## 依赖倒置原则

### 允许的依赖关系

```
App 层
  ↓
Demo 层 / Task 层
  ↓
Driver 层
  ↓
Interface 层
  ↓
HAL 库
```

### 禁止的依赖关系

```
❌ Driver 层 → HAL 库（必须通过 Interface 层）
❌ Interface 层 → App 层（下层不能依赖上层）
❌ Driver 层 → MCU 厂商头文件（如 stm32f4xx_hal.h）
```

### 抽象层常量封装

```c
/* bsp_board.h 中定义 */

/* 超时常量：封装 HAL 依赖 */
#define BSP_WAIT_FOREVER  0xFFFFFFFFU  /* 替代 HAL_MAX_DELAY */
#define BSP_NO_WAIT       0U           /* 立即返回 */

/* 临界区常量 */
#define BSP_CRITICAL_MAX_NESTING  32U  /* 临界区嵌套最大深度 */
```

## 验收标准

每个里程碑完成后，必须满足以下验收标准：

1. **编译通过**：无编译错误和警告
2. **Shell 验收**：通过 Shell 命令验证功能
3. **代码规范**：符合 Docs/代码规范.md
4. **注释完整**：所有公开 API 有 Doxygen 注释
5. **无依赖违规**：Driver 层不直接依赖 HAL 库
