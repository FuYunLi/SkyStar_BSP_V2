# 阶段一：核心接口层 + 调试基础

## 目标

建立 UART 接口层、Shell 交互、日志系统，为后续所有开发提供完整的调试手段。

***

## CubeMX 配置

### UART1 (调试串口)
- **引脚**: `PA9` (TX), `PA10` (RX)
- **参数**: Baud Rate `115200`, Word Length `8 Bits`, Parity `None`, Stop Bits `1`
- **NVIC**: 开启 `USART1 global interrupt` (优先级抢占0，子优先0)
- **DMA**:
  - `USART1_RX`: `DMA2 Stream 2`, Channel 4, Mode `Circular`, Direction `Peripheral to Memory`
  - `USART1_TX`: `DMA2 Stream 7`, Channel 4, Mode `Normal`, Direction `Memory to Peripheral`

### TIM/DWT
保留 SysTick 给 HAL 库。若需要基本定时器，可开启 `TIM6` (预分频 `83`，重装载 `999` 产生 1ms 中断)。

## M1 — UART 接口 + printf 重定向

### 提交信息

```
feat(interface): port_critical - 临界区保护接口
feat(interface): port_uart - DMA + lwrb 环形缓冲区接收
feat(middleware): lwrb - 轻量级环形缓冲区移植
```

### 内容清单

1. **port_critical.h/c**：临界区进入/退出接口，裸机用中断开关实现
2. **Middleware/LwRB/lwrb.h**：单头文件库，直接引入
3. **port_uart.h/c**：全部 API（发送/接收/回调/统计），含 `extern "C"`，数值宏加括号
4. **接收缓冲**：使用 lwrb 实现 DMA 循环接收 + 环形缓冲区读取，临界区保护多线程访问
5. **fputc 重定向**：重定向到 `port_uart_write_async`
6. **移植 printf**：支持（用于无 Shell 时的调试输出）

### port_uart API 设计

```c
/* 初始化配置 */
typedef struct
{
    uint32_t baudrate;              /* 波特率，0 表示沿用 CubeMX 默认配置 */
    uint8_t *rx_dma_buf;            /* DMA 接收原始缓冲区 */
    uint16_t rx_dma_buf_size;       /* DMA 缓冲区大小 */
    lwrb_t *rx_rb;                  /* lwrb 接收环形缓冲区 */
    lwrb_t *tx_rb;                  /* lwrb 发送环形缓冲区（可选） */
    port_async_cb_t on_tx_complete; /* 发送完成回调 */
    port_async_cb_t on_error;       /* 硬件错误回调 */
    void (*on_rx_data)(port_uart_id_t uart, uint16_t len, void *user_ctx); /* 接收数据回调 */
    void *user_ctx;                 /* 透明指针 */
} port_uart_config_t;

/* 初始化 */
bsp_status_t port_uart_init(port_uart_id_t uart, const port_uart_config_t *cfg);

/* 同步发送 */
bsp_status_t port_uart_write_sync(port_uart_id_t uart, const uint8_t *data, uint16_t len, uint32_t timeout_ms);

/* 异步发送 */
bsp_status_t port_uart_write_async(port_uart_id_t uart, const uint8_t *data, uint16_t len, port_async_cb_t cb, void *user_ctx);

/* 读取数据 */
int port_uart_read(port_uart_id_t uart, uint8_t *data, uint16_t len);

/* 获取接收缓冲区可读字节数 */
uint16_t port_uart_get_rx_available(port_uart_id_t uart);
```

### 验收标准

- `printf("Hello V2\r\n")` 从串口输出，示波器/串口助手可见
- 无编译警告
- 符合代码规范

## M4 — port_tick + port_dwt

### 提交信息

```
feat(interface): port_tick + port_dwt - 软件定时与精确延时
```

### 内容清单

1. **port_tick.c/h**：`port_tick_delay_ms()`、`soft_timer_t` 结构体
2. **port_dwt.c/h**：`port_dwt_delay_us()`（DWT 精确微秒延时）

### port_tick API 设计

```c
/* 获取当前时间戳（ms） */
uint32_t port_tick_get(void);

/* 延时（ms） */
void port_tick_delay_ms(uint32_t ms);

/* 软件定时器结构体 */
typedef struct
{
    uint32_t start;      /* 启动时间戳 */
    uint32_t interval;   /* 定时间隔 */
    bool active;         /* 是否激活 */
} soft_timer_t;

/* 软件定时器检查 */
bool soft_timer_check(soft_timer_t *timer);
```

### port_dwt API 设计

```c
/* 初始化 DWT */
void port_dwt_init(void);

/* 获取当前计数 */
uint32_t port_dwt_get(void);

/* 精确延时（us） */
void port_dwt_delay_us(uint32_t us);

/* 获取从启动到现在的微秒数 */
uint64_t port_dwt_get_us(void);
```

### 验收标准

- Shell 命令 `delay_test`，测试 1ms / 100us 延时误差（用 DWT 计时后 log 输出）
- 延时误差在可接受范围内（<1%）

## 阶段完成标准

阶段一完成后，应满足以下标准：

1. **编译通过**：无编译错误和警告

3. **日志可用**：所有模块使用 EasyLogger 输出日志
4. **延时准确**：port_tick 和 port_dwt 延时准确
5. **代码规范**：符合 Docs/代码规范.md
