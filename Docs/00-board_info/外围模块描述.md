## 4. 电源树结构 (Power Tree)

* **供电路径**:
* `ONBOARD_+3V3` -> 供电至 U67、U68、U69 (模拟开关 VCC 引脚)，RV1 (电位器)，无源蜂鸣器驱动网络。
* `EXT_+3V3_OUT` -> 供电至 U70 (传感器 VDD)，H18 (外部ADC排针)。
* `DCDC_OUT_VCC_5V` -> 供电至 有源蜂鸣器驱动网络，舵机 PWM 上拉电阻 (R126, R127)。
* `EXT_+5V0_OUT` -> 供电至 H19 (舵机接口排针引脚 3, 4)。


* **关键去耦电容**:
* 模拟开关 U67、U68、U69 的 VCC 引脚旁各自并联 100nF X7R 去耦电容 (C155, C170, C171)。
* 5V 有源蜂鸣器电源处并联 C161 (100nF) 和 C163 (10uF) 滤波电容。
* 3.3V 无源蜂鸣器电源处并联 C162 (100nF) 和 C164 (10uF) 滤波电容。
* U70 接口 VDD 处并联 C172 (100nF) 滤波电容。

## 6. 视觉审核警告 (Hardware Warnings)

* **悬空引脚**: 未标明明显悬空引脚。
* **潜在冲突**:
* 逻辑反相风险：`SERVO_PWM1` 与 `SERVO_PWM2` 经过 NPN 三极管 (SS8050) 开漏驱动，构成了反相器。MCU 输出高电平时，H19 接口侧的 PWM 信号被拉低至 GND，软件底层驱动需作占空比反相处理。
* 过压烧毁风险：H18 (外部 ADC 接口) 的 `ADC123_IN8` 与 `ADC123_IN9` 线路已加批注：“最大只能接入3.3V，超过有可能造成芯片损坏”。外部输入未设计电阻分压网络，存在硬件级过压风险。
