## 1. 硬件模块概览 (Functional Blocks)

* **图纸总述**: 该图纸为“天空星-筑基学习板”的 I2C 设备模块原理图（版本V1.0），未标明主控芯片具体型号、性能、频率及内存参数，主要展示了多路 I2C 设备的挂载及总线中继/电平转换设计。
* **包含的核心模块**: I2C总线电平转换/中继电路 (PCA9517ADP)、EEPROM存储器 (AT24C02C)、电压电流监测模块 (INA226)、高精度RTC时钟 (SD3078)、温湿度传感器 (AHT20-F) 及外部 I2C/触摸排针扩展接口。

## 3. 关键通信总线拓扑 (Bus Topology)

* **I2C1 原始总线 (PRE)**:
* **SCL**: MCU_PB6 -> `I2C1_SCL_PRE` -> U77/U78 的 SCLA(Pin2)。总线经 R66(2.2k) 上拉至 `SKYSTAR_+3V3`。
* **SDA**: MCU_PB7 -> `I2C1_SDA_PRE` -> U77/U78 的 SDAA(Pin3)。总线经 R67(2.2k) 上拉至 `SKYSTAR_+3V3`。


* **I2C1 板载总线 (ONBOARD)**:
* **SCL**: U77_SCLB(Pin7) -> `I2C1_SCL` -> U40/U41/U42/U43 对应 SCL 引脚。总线经 R178(2.2k) 上拉至 `ONBOARD_+3V3`。
* **SDA**: U77_SDAB(Pin6) -> `I2C1_SDA` -> U40/U41/U42/U43 对应 SDA 引脚。总线经 R179(2.2k) 上拉至 `ONBOARD_+3V3`。


* **I2C1 外部扩展总线 (OUT)**:
* **SCL**: U78_SCLB(Pin7) -> `I2C1_SCL_OUT` -> 经 R176(75Ω阻抗匹配) -> H11(Pin2)。总线经 R180(4.7k) 上拉至 `EXT_+3V3_OUT`。
* **SDA**: U78_SDAB(Pin6) -> `I2C1_SDA_OUT` -> 经 R177(75Ω阻抗匹配) -> H11(Pin3)。总线经 R181(4.7k) 上拉至 `EXT_+3V3_OUT`。
*(注：可通过选焊 0Ω 电阻 R172~R175 直接短接 PRE、ONBOARD 及 OUT 网络，跳过中继芯片)*


* **TOUCH I2C 总线**:
* **SCL**: MCU_PD10 -> `TOUCH_SCL` -> H12/H21(Pin2)。无局部上拉电阻。
* **SDA**: MCU_PE13 -> `TOUCH_SDA` -> H12/H21(Pin3)。无局部上拉电阻。



## 4. 电源树结构 (Power Tree)

* **供电路径**:
* `SKYSTAR_+3V3`: 为主控侧 I2C 上拉网络及中继芯片 U77/U78 的 VCCA (1脚) 供电。（上游路径未标明）
* `ONBOARD_+3V3`: 为板载从机群 (U40, U41, U42, U43) 及中继芯片 U77/U78 的 VCCB (8脚) 供电。（上游路径未标明）
* `EXT_+3V3_OUT`: 为外部扩展接口 (H11, H12, H21) 供电。（上游路径未标明）
* `BAT_PIN+` / B1纽扣电池: 经 R74(0Ω) 连接至 U41(SD3078) 的 VBAT 管脚作为后备电源。


* **关键去耦电容**:
* **U40 (EEPROM)**: VCC 经 R65(0Ω) 供电，管脚近端接 100nF(C116) 对地。
* **U42 (INA226)**: VS 经 R78(0Ω) 供电，管脚近端并联 100nF(C121) 和 10uF(C122) 对地。
* **U41 (RTC)**: VDD 经 R72(0Ω) 供电，管脚近端并联 100nF(C117) 和 10uF(C118) 对地。
* **U43 (Temp/Hum)**: VDD 经 R79(330Ω) 和 R80(0Ω) 供电，管脚近端并联 100nF(C123) 和 10uF(C124) 对地。



## 5. 被动元件与外围配置 (Passive BOM & Config)

* **晶振电路**: 未标明。
* **拨码开关/跳线帽**:
* **SW2 (4位DIP拨码)**: 控制 U40 的 A0, A1, A2 (硬件地址) 及 WP (写保护)。相关引脚默认通过 R68~R71 (10k) 下拉至地(低电平)；拨码闭合时接入 `ONBOARD_+3V3`(高电平)。
* **JUMP5**: RTC 信号配置跳线，用于将 SD3078 的 INT 和 F32K 信号灵活桥接至主控引脚或悬空。
* **JUMP7**: INA226 报警引脚配置，用于选择将 Alert 引脚外接或强制拉低。


* **LED/按键**:
* **LED3 (红色)**: INA226 报警指示灯。阳极经 R76(2k) 串联至 `ONBOARD_+3V3`，阴极接 U42_Alert 引脚，为低电平驱动。



## 6. 视觉审核警告 (Hardware Warnings)

* **悬空引脚**:
* U43 (AHT20-F) 的 Pin 1 和 Pin 4 为原厂设计悬空 (NC)。
* 若 JUMP5 不短接跳线帽，U41 (SD3078) 的 F32K 时钟输出信号处于完全悬空状态。


* **潜在冲突**:
* **总线电容过载风险**: 板载 `I2C1_SCL`/`I2C1_SDA` 网络同时挂载 4 个从机器件，图内注释明确指出“这么多IIC设备，导致负载电容过大，上升沿缓慢”。硬件设计已引入 PCA9517 作为隔离缓冲予以解决，且中继器启用必须保证使能引脚(EN)正常拉高。
* **触摸屏接口复用冲突**: 注释明确提示 H12/H21 `TOUCH_SCL/SDA` (PD10, PE13) 接口与“屏幕扩展板的触摸I2C共用”，由于此处未设置上拉电阻，若直连不支持内部上拉的外设，或同时将其复用为普通 IO，存在通信失败和电平驱动逻辑冲突风险。
