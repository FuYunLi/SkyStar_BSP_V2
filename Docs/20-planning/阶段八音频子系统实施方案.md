> 板级依据:`Docs/00-board_info/天空星筑基学习板-引脚分配总表.xlsx`(以其为准,规划冲突处见第 2 节偏差表)

## 1. 目标

打通 TF 卡(FatFS)→ WAV 解析 → I2S2 DMA → ES8388 → HT6872 功放的完整播放链路,并在 SPI2(Flash/IMU)与 I2S2 共享引脚(PB10/PC2/PC3)上建立板级总线仲裁机制。产出 3 个可编译、可 Shell 验收的提交。

## 2. 硬件事实与规划偏差

引脚总表核实结论(冲突处**以总表为准**):

| 项 | 规划文档说法 | 引脚总表/原理图事实 | 采纳 |
|---|---|---|---|
| I2S2_WS | PB9 | PB9 → ES8388_WS,无冲突 | PB9 |
| I2S2_CK | PB10 | PB10 与 SPI2_SCK 复用,**SW7 BIT3** 仲裁 | PB10 |
| I2S2_SD | PC3 | PC3 与 SPI2_MOSI 复用,同上 | PC3 |
| I2S2_ext_SD | PC2 | PC2 与 SPI2_MISO 复用,同上;本阶段仅播放,录音留待后续 | PC2(暂不使能) |
| I2S2_MCK | PC6 | PC6 → ES8388_MCLK,无冲突 | PC6 |
| ES8388 控制 | I2C1 地址 0x10 | 与 I2C1 总线设备表一致 | PORT_I2C_1 @ 0x10 |
| 功放使能 | **PA4 GPIO_Output** | **PA4 实为继电器控制**;HT6872 使能走 **SW7 BIT1**(内部信号,1K 下拉默认静音),由 PCA9555 输出控制 | **PCA9555 控 BIT1,不动 PA4** |
| 切换方式 | SW7 拨码物理切换 | PCA9555(Port0,输出位)软件控制模拟开关,与拨码并联,**软件优先** | PCA9555 软件 |

既有代码资产(必须复用,不重造):

- `bsp_imu.c` 已实现 PCA9555 切换:Port0 **Pin2 ↔ BIT3**,写低=SPI2 侧导通,写高=I2S2 侧导通。该逻辑将从 bsp_imu 中**上收到总线仲裁器**,bsp_imu 改为通过仲裁器加锁。
- `dev_pca9555` 完整可用(影子寄存器 + 位级读写);全局实例 `g_pca_led` 定义于 `bsp_led.c`。
- `port_i2c` 逻辑通道 `PORT_I2C_1`;`dev_icm42688`/`dev_w25q` 挂 SPI2,是仲裁的"被挂起方"。

**待实现时核实**:BIT1(功放使能)对应的 PCA9555 引脚号。参照 BIT3↔Port0 Pin2 的对应关系推算为 Port0 Pin0,上板用 `dev_pca9555_read_port` 回读核实后写入宏定义。

## 3. CubeMX 配置(SkyStar_BSP_HAL.ioc)

1. **I2S2**:模式 Half-Duplex Master(Transmit),音频标准 Philips,44.1kHz,16-bit Data;勾选 Master Clock Output(供 ES8388 MCLK,PC6)。注意 I2S 时钟来自 PLLI2S,CubeMX 需检查 44.1kHz 系列的 PLLI2S 分频无偏差报警。
2. **DMA**:SPI2_TX/I2S2_TX 通道,DMA1 Stream4 Channel0,Circular,HalfWord,Memory Increment;NVIC 开启 DMA 流中断与 SPI2 全局中断(半传输/传输完成回调依赖)。
3. **不配置** PA4 功放使能(见偏差表);PC2 保持 SPI2 复用现状。
4. ⚠️ 重新生成会覆盖 `Core/`:生成后按惯例目检增量,重点核对 `stm32f4xx_it.c` 新增 DMA 流 IRQHandler 与 `hal_conf.h` 的 `HAL_SPI_MODULE_ENABLED` 共存。

## 4. 模块设计(接口→驱动→Board→Demo 分层)

### 4.1 M30:`BSP/Interface/port_i2s.c/h` + `BSP/Board/bsp_bus.c/h`

**port_i2s**(HAL 止步于此层):

- 逻辑 ID + 静态映射表,沿用 `port_uart.c` 的 `s_uart_map` 范式;本阶段仅 `PORT_I2S_1` 一个通道。
- API:

```c
typedef void (*port_i2s_tx_cb_t)(void *user_ctx);          /* 半传输/全传输共用 */
bsp_status_t port_i2s_init(port_i2s_id_t id);               /* 校验映射表 + MX 初始化句柄就绪 */
bsp_status_t port_i2s_start_dma(port_i2s_id_t id,
        const uint16_t *buf, size_t half_samples,
        port_i2s_tx_cb_t half_cb, port_i2s_tx_cb_t full_cb, void *user_ctx);
bsp_status_t port_i2s_stop(port_i2s_id_t id);
```

- DMA 循环模式;`HAL_I2S_TxHalfCpltCallback`/`HAL_I2S_TxCpltCallback` 在本层实现并按句柄路由到注册回调;`hal_to_bsp_status()` 翻译错误;回调内只置标志/投递,禁止阻塞。
- it.c 显式绑定 `DMA1_Stream4_IRQHandler → HAL_DMA_IRQHandler`(铁律:WEAK 需主动核对)。

**bsp_bus**(板级总线仲裁器,E4 核心):

```c
typedef enum { BSP_BUS_SPI2_I2S2 = 0, BSP_BUS_MAX } bsp_bus_id_t;
typedef enum { BSP_BUS_OWNER_NONE, BSP_BUS_OWNER_SPI2, BSP_BUS_OWNER_I2S2 } bsp_bus_owner_t;

bsp_status_t bsp_bus_acquire(bsp_bus_id_t bus, bsp_bus_owner_t owner);
bsp_status_t bsp_bus_release(bsp_bus_id_t bus, bsp_bus_owner_t owner);
bsp_bus_owner_t bsp_bus_current(bsp_bus_id_t bus);
```

- `port_critical` 保护 owner 状态;acquire 冲突返回 `BSP_EBUSY`。
- acquire I2S2 侧的动作序列(自底向上):①通知挂起 SPI2 上层(`bsp_imu` 提供采样挂起/恢复接口)→ ②`port_spi` 反初始化 SPI2 句柄 → ③PCA9555 切 BIT3 拉高(音频侧)→ ④I2S2 就绪。release 反序。SPI2 侧 acquire 由改造后的 `bsp_imu_init`/恢复接口走同一仲裁器。
- `bsp_imu.c` 现有直写 PCA9555 的代码改为调用仲裁器(最小改动:初始化改 `bsp_bus_acquire(SPI2)`,新增 `bsp_imu_suspend()/bsp_imu_resume()` 供仲裁器回调)。

### 4.2 M31:`BSP/Driver/dev_es8388.c/h` + `dev_ht6872.c/h`

**dev_es8388**(仅调 `port_i2c`,PORT_I2C_1,地址 0x10):

- 寄存器级驱动:上电序列(Chip Power Mgmt→时钟分频→DAC/ADC 通路→混音/音量);API:

```c
bsp_status_t dev_es8388_init(void);                     /* 全套初始化,含软复位 */
bsp_status_t dev_es8388_set_dac_volume(uint8_t vol_0_100);
bsp_status_t dev_es8388_set_rate(uint32_t sample_rate);
bsp_status_t dev_es8388_mute(bool en);
```

- 音量线性映射到 LOUT1/ROUT1 寄存器(0x2E/0x2F),0-100 → 0-0x5F 衰减档。

**dev_ht6872**(功放使能):

- `dev_ht6872_init()/dev_ht6872_enable(bool)`,内部经 `dev_pca9555` 写 BIT1 对应位;默认状态与 BIT1 的 1K 下拉(静音)一致,杜绝上电爆音。

### 4.3 M32:`APP/demos/app_audio_demo.c/h`(含播放引擎)

- **WAV 解析**:校验 RIFF/fmt 块,提取声道数/采样率/位宽,跳过 data 块前偏移(不硬编码 44,按 chunk 解析)。
- **双缓冲引擎**:两块 `static uint16_t buf[2][2048]`(共 8KB,上栈禁区,文件级静态);**半/全传输回调内只置 volatile 标志**,实际 `f_read` 填充在 MultiTimer 周期任务(5ms)中执行——规划原文"回调内 f_read"会致 FatFS 在 ISR 上下文重入 SDIO DMA,此处为有据偏差,提交正文说明。
- **bsp_audio 薄封装**(Board 层):`bsp_audio_play(path)` 完成仲裁 acquire→es8388 参数配置→ht6872 使能→port_i2s_start_dma 的编排;`bsp_audio_stop()` 反序。
- Shell 命令:`audio_bus_switch`、`audio_init`、`audio_set_vol`、`play_wav <path>`、`play_stop`(均 `SHELL_EXPORT_CMD`,注册于 demo)。

## 6. 风险与对策

1. **PLLI2S 44.1kHz 精度**:CubeMX 生成后核对实际 SCLK 偏差,超限则调 PLLI2S 参数(生成时人工复核,不静默接受警告)。
2. **仲裁死锁**:acquire/release 全路径配对,`bsp_audio_stop` 失败路径也必须 release;调试期仲裁器打印状态迁移日志(EasyLogger)。
3. **ISR 绑定遗漏**:DMA 流 IRQHandler 不绑定则回调静默不触发(WEAK),按启动链 SOP 主动核对 it.c。
4. **上电爆音**:BIT1 下拉默认静音是硬件保底,软件仅在 es8388 初始化完成且音量写入后才使能功放。
