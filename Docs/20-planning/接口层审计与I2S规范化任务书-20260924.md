### 1.2 已核对且**没问题**的（不要重复劳动）

- Interface/Driver 层 `printf` **0 处**（符合"日志必须走 log_x"）。
- `DMA1_Stream4_IRQHandler`、`SPI2_IRQHandler`、`SDIO_IRQHandler`、`DMA2_Stream*` 均已在 `Core/Src/stm32f4xx_it.c` 显式绑定（嵌软硬约束第 1 条满足）。
- HAL 句柄/错误码未泄漏到 Board 层之上；`hal_to_bsp_status()` 在 Interface 层内完成翻译。
- I2S 与 SPI2 的**引脚选择正确**：CubeMX 的 SPI2 用 `PB10(SCK)/PC2(MISO)/PC3(MOSI)`，`port_i2s` 用 `PB9(WS)/PB10(CK)/PC3(SD)/PC6(MCK)`，二者在 PB10/PC3 重叠——正是"同一组走线分时复用"的设计前提，注释与实现一致。
- `bsp_bus` 的"人格互斥"处理是对的（切 I2S 前先反初始化 SPI2、切回前停 I2S 并 `MX_SPI2_Init()` 重建），是全仓处理得最好的一处跨模块耦合。
- `port_i2c.h` 的 `0x80` 偏置命名空间、`port_pwm.h` 的功能型逻辑 ID，都是"改表即换板"的正面样板。

## 第二部分　为什么 I2S 不能像 UART/SPI 那样纯表驱动（两条硬件事实）

**事实 A：音频时钟是板级单例，不是通道属性。**
F407 上 I2S1/2/3 的内核时钟同源于**唯一一份 PLLI2S VCO**（`PLLI2SN`/`PLLI2SR` 全局共享）。因此
44.1 kHz 家族（MCLK 11.2896 MHz）与 48 kHz 家族（12.288 MHz）**不可同时成立**；把 N/R 塞进
"每通道一条表项"等于把全局资源的所有权撒进多个对象，冲突时无人负责。
（补充：F407 的 I2S 内核时钟源只有 PLLI2S；带 I2S 时钟源可选位的是 F412/F446/F469 一类后续子系列——
**以 RM0090 为准**，但不影响本仓结论。）

**事实 B：SPI2 与 I2S2 是同一硬件块的两种人格，运行时互斥。** 所以所有权必须有一个显式仲裁者——
本仓已经存在，就是 `bsp_bus`。这条约束也是"I2S 与别的 port_ 长得不一样"的根本原因。

⇒ 能对象化的是**通道**（实例、DMA、引脚、NVIC）；不能对象化的是**音频时钟域**与**实例人格**。

## 第三部分　目标架构（四层，已有三层半）

```
i2s_clock      【新增，单例】唯一持有 PLLI2S；对外只接受"音频时钟族"请求；N/R 由目标 MCLK 计算或查表
port_i2s       【改造】表驱动人格 + config 参数 + 循环 DMA + 半/全回调；向 i2s_clock 申请时钟域，不自带魔数
bsp_bus        【已有，保留】SPI2/I2S2 人格所有权、引脚与外设反初始化/重建顺序
dev_es8388 / dev_ht6872 【已有，保留】codec 与功放
```

映射表示例（**唯一硬件事实集中处**，换板只改这张表）：

```c
typedef struct
{
    SPI_TypeDef         *instance;       /* I2S 模式仍写 SPI2 基址 */
    DMA_Stream_TypeDef  *dma_stream;   IRQn_Type dma_irqn;   uint32_t dma_channel;
    GPIO_TypeDef *ws_port;  uint16_t ws_pin;      /* PB9  */
    GPIO_TypeDef *ck_port;  uint16_t ck_pin;      /* PB10 */
    GPIO_TypeDef *sd_port;  uint16_t sd_pin;      /* PC3  */
    GPIO_TypeDef *mck_port; uint16_t mck_pin;     /* PC6，不用 MCK 时置 NULL */
    uint8_t       af;                               /* GPIO_AF5_SPI2 */
} port_i2s_map_t;
```

## 第四部分　任务书（可直接派给任一 agent，按序做，每步单独可回滚）

### 范围
仅 `BSP/Interface/port_i2s.*`、新增 `BSP/Interface/i2s_clock.*`、唯一使用者 `BSP/Board/bsp_audio.c`、
以及 A2/A3/A5 的小改动。**禁止**顺带重构 `bsp_bus`、codec 或音频策略。

### 契约改动（前 → 后）

| 现在 | 目标 | 波及 |
|---|---|---|
| `bsp_status_t port_i2s_init(port_i2s_id_t id)` | `port_i2s_init(port_i2s_id_t id, const port_i2s_config_t *cfg)`（含 `audio_family, data_bits, mode(MASTER/SLAVE), mclk_enable`） | `bsp_audio.c` 1 处调用 |
| `port_i2s_start_dma(id, const uint16_t *buf, size_t samples, …)` | `port_i2s_start_dma(id, const void *buf, size_t bytes, …)`（半/全回调语义改为"字节数一半"） | `bsp_audio.c` 的缓冲与填充计数 |
| `#define PORT_I2S_PLLI2S_N 271 / _R 6` | 由 `i2s_clock` 按目标族计算或查两族表；删除魔数宏 | `i2s_clock` 内部 |
| `Port_I2S_1 = 0`（物理却是 I2S2） | 逻辑 ID 改名对齐（`PORT_I2S_ES8388` 或 `PORT_I2S_2`），或补一句文档化映射 | 上层 2 处引用 |

### 顺带做掉的低成本项
- A2：`port_gpio_init()` 改为遍历 `gpio_mapping[]` 去重后按端口开时钟；删除 `GPIOH` 死项。
- A3：表里加 `default_level`（含 `unused/NA` 语义），init 逐脚预置，CS 类预置为高。
- A5：`port_i2s_deinit()` 内 `HAL_GPIO_DeInit` 仅 I2S 专属脚（PB9/PC6）；**共用脚 PB10/PC3 不动**，交回 `bsp_bus`/`MX_SPI2_Init()` 语义。

### 判据（必须给数字，不接受"我修好了"）
1. `play_wav 0:/tour.wav` → `Playing … (44100Hz 2ch 16bit)` → `Playback finished`，耗时与文件时长差 < 5%；
2. `audio_bus_switch i2s` ⇄ `spi` **连续 200 次**，全程无死锁，`Current owner: NONE`，`flash_id` 前后一致；
3. `imu_read` 在 200 次切换后仍正常（回归本周 IMU 修复）；
4. 读回 `RCC->PLLI2SCFGR` 与 `SPI2->I2SCFGR/I2SPR`，反算 MCLK/位速率与目标一致（48 kHz 素材时同理）；
5. `fatfs_test align` 仍 9/9（`rejects=+2`、`staged=+3`），`fatfs_test crc 0:/tour.wav` = `7A6FD6F4`；
6. 编译 0 Error；报告 `Code/RO/RW/ZI` 与 `.ANY` 余量变化（当前 112 B，不得转负）。

### 禁改清单
- 不动 `Drivers/` 任何 HAL 文件；不动 `Middleware/`；
- 不在 port 层引入 printf；
- 不新增 `BSP_WAIT_FOREVER`；
- 不顺手"优化" `bsp_audio` 的缓冲策略（它刚修好吞错与 EOF 判据）。

### 回滚点
改造前建 `backup/25号-i2s规范化前-<hash>`；每步一个提交（`refactor(interface)` / `feat(interface): i2s_clock` / `fix(board): bsp_audio 适配` / `fix(interface): port_gpio 时钟与默认电平`）。

### 完成后需同步的三处
`ARCHITECTURE.md` 第 4 节契约（如新增"音频时钟单例"约束）、第 8 节台账、第 9 节勾掉 A1/A2/A3/A5 相应条目；并在本文件末尾追加"已定案于 <commit>"。

## 第六部分　什么时候该回来做（触发条件）

任一成立即启动任务书：
1. 需要**录音/回读方向**（ES8388 ADC 已具备，接口现在接不进来）；
2. 需要 **48 kHz 家族或 24/32-bit** 素材；
3. 需要**第二路 I2S**（届时"音频时钟单例"的必要性会立刻显形）；
4. 换了板子/CPU，需要重画引脚与时钟表；
5. A1（`MX_*` 反向依赖）在某次 CubeMX 重新生成后真的咬过人。

其中第 5 条若发生，则 A1 优先于本任务书——它更便宜且是"静默失效"类。
