审查当前未提交的改动(git diff + 新增未跟踪文件),对照 Docs/10-standards/代码规范.md 与 Docs/10-standards/工程规范.md 逐条检查,并额外覆盖嵌入软专项清单:

1. **ISR 安全**:中断/回调内无非重入调用、无 malloc/printf、共享变量 volatile;
2. **阻塞与延时**:ISR/定时器回调内无忙等长延时;HAL_MAX_DELAY 误用;
3. **边界与溢出**:数组/缓冲区边界检查、整型提升、16 位回绕;
4. **分层铁律**:HAL 类型/句柄是否泄漏出 Interface 层;依赖方向是否自上而下;
5. **栈风险**:新加大数组/大结构体在栈上,评估调用链栈深度;
6. **规范符合**:命名前缀(port_/dev_/bsp_/app_)、注释、头文件保护宏、.clang-format 风格;
7. **魔法数字**:寄存器值/时序参数应有具名宏或注释来源(datasheet 章节)。

输出:按严重级别(阻断/建议/提示)分组列出问题,每条附 文件:行号 与修改建议;确认后等待用户决定是否修复,不自动改代码。
